# Landweigh

Importers sourcing from China end up with dozens of product listings across 1688 and Alibaba that cannot be compared with each other.
Every listing uses a different layout, many are only in Chinese, prices come in quantity tiers and SKU variants quoted per piece, set or carton,
the minimum order is buried in the description, and weights and packaging are missing or hidden. Today this gets copied by hand into notes or spreadsheets,
which is slow,error-prone and repeated for every product in every category.
Better looks like this: paste a product link and get back one comparable record with the real price at the quantity you would order and a landed cost per unit.
